# Personal CV Website

## Description
A personal CV website built using HTML5 to present professional information, technical skills, career history, educational qualifications, and certifications.

## Features
- Personal and contact information
- Professional summary
- Technical skills
- Career history
- Education and certifications
- SEO metadata

## Technologies Used
- HTML5



Navigate to the project folder:

cd Projects

## How to Run
Open the `index.html` file in any modern web browser. No additional installation is required.
